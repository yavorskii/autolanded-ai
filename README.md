# AutoLanded AI (Decision Support System)

Інтелектуальна система підтримки прийняття рішень (DSS) для аналітики страхових автоаукціонів США (Copart, IAAI), мультимодальної оцінки пошкоджень кузова, підбору оригінальних запчастин за стандартами EPC та розрахунку повної собівартості імпорту за податковим законодавством України (Закон № 2611-VIII).

---

## Технологічний стек
- **Backend:** Java 21 LTS, Spring Boot 3.3.4, Spring Data JPA, Spring Validation, Lombok, Jackson
- **Frontend:** React 18, TypeScript, Vite, Vanilla Dark CSS Design System, Lucide Icons
- **Database:** PostgreSQL 16
- **Computer Vision & AI:** Google Gemini 1.5 Flash Vision Multimodal API + Domain Heuristic Expert Engine
- **DevOps:** Docker Compose multi-stage containers

---

## Ключовий функціонал

1. **VIN Decoder Engine (NHTSA API Integration):**
   * Миттєве декодування 17-значного VIN-коду в специфікацію автомобіля (рік, марка, модель, тип палива, об'єм двигуна або ємність батареї в кВт·год).
   * Автоматичне виявлення типу електрифікації (EV, Hybrid, Plug-in Hybrid).

2. **Мультимодальний ШІ-дефектувальник (Gemini Vision):**
   * Детектування пошкоджених зон кузова (`FRONT_BUMPER`, `RIGHT_HEADLIGHT`, `HOOD`, `RIGHT_FENDER`, `COOLING_PUMP`).
   * Інспекція салону та статус спрацювання подушок безпеки (Airbags).
   * **Domain Heuristics (Експертні правила):**
     * Електрокар + Статус Flood (затоплення) ➡️ присвоєння статусу `TOTAL_LOSS` через ризик деградації високовольтної батареї.
     * Tesla Model X/S + удар у праве крило ➡️ попередження про ризик пошкодження контуру охолодження батареї та помпи.
   * Детермінований офлайн-демо режим для захисту без інтернет-з'єднання.

3. **Каталог деталей, OEM парт-номери та Вибух-схеми (EPC):**
   * Каталогізація деталей за міжнародними стандартами EPC (RealOEM, Tesla EPC, VAG ETKA).
   * Збереження заводських **OEM Парт-номерів** (наприклад: `1083983-00-A` для Tesla, `34336857405` для BMW i3).
   * Номери позицій на вузлових кресленнях (`#14`, `#1`, `#3`).
   * **3 Стратегії закупівлі деталей:**
     1. *Оригінал б/в у колір авто* (без потреби фарбування).
     2. *Новий Тайвань / ліцензія + фарбування*.
     3. *Оригінал б/в під фарбування*.
   * Прямі deep links на пошук деталей на **Avto.pro** та **Allegro.pl**.
   * Динамічний EPC-резолвер для відкриття оригінальних схем на `epc.tesla.com`, `realoem.com`, `7zap.com` та `partsouq.com`.

4. **Митний калькулятор України (Закон № 2611-VIII):**
   * **Електромобілі (EV):** 0% мито, 0% ПДВ, 0% пенсійний фонд, акциз **1 євро за 1 кВт·год** ємності батареї.
   * **ДВЗ та гібриди:** 10% мито, акциз за формулою `ставка x об'єм x вік`, 20% ПДВ.

5. **Аналітика ринку Auto.ria (Like-for-Like):**
   * Статистичний аналіз вибірки прямих аналогів: **Низ ринку (P25)**, **Медіана**, **Топ ринку (P75)**.
   * Розрахунок чистого економічного прибутку та рентабельності інвестиції (ROI).
   * Фінальний вердикт СППР: `STRONG_BUY`, `MODERATE_BUY`, `CONSIDER`, `RISKY`, `TOTAL_LOSS`.

6. **Адаптивна конфігураційна панель тарифів СТО:**
   * Базові середньоринкові нормативи по Україні.
   * Можливість вибору регіональних пресетів ("Івано-Франківськ", "Київ / Центр", "Власний гараж") або введення власних тарифів (фарбування, нормо-година, відновлення подушок).

## Запуск проєкту

### 1. Швидкий запуск через Docker Compose (Всі сервіси під ключ)
```bash
docker compose up -d
```
* **Frontend UI:** `http://localhost:3001`
* **Backend REST API:** `http://localhost:8081`
* **PostgreSQL Database:** `localhost:5434` (User: `autolanded_user`, DB: `autolanded_db`)

### 2. Локальний запуск для розробки
```bash
# База даних у Docker
docker compose up -d autolanded-postgres

# Бекенд (Spring Boot)
cd backend
mvn spring-boot:run

# Фронтенд (Vite React)
cd frontend
npm install
npm run dev
```
